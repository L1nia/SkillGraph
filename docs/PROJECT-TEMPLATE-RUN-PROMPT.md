# Промпт запуска project-template-builder

Скопируйте шаблон в поле запуска цепочки и замените значения в угловых скобках. Не добавляйте сюда визуальные требования, стек, обязательные артефакты, этапы агентов или критерии приёмки: они находятся в скилле и применяются автоматически.

```text
Создай рабочий проект <НАЗВАНИЕ> в директории <АБСОЛЮТНЫЙ ПУТЬ>.

Предметная задача:
<ЧТО ДОЛЖЕН ДЕЛАТЬ ЭКРАН, КАКИЕ ПОЛЯ, ДАННЫЕ И API НУЖНЫ>

Используй skill://local.project-template-builder@1.0.6 как обязательный контракт.
```

Промпт определяет только предметную задачу. Внешний вид, архитектура, обязательные файлы, агентная декомпозиция и визуальная приёмка определяются `project-template-builder`. При расхождении пересказа этих правил в промпте со скиллом применяется скилл.
