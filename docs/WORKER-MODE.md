# Worker-режим AI-провайдеров

SkillGraph не запускает и не автоматизирует окна AI-клиентов. Codex, Cursor,
Claude, Copilot, DeepSeek, Qwen, локальная или другая модель становится доступным исполнителем
только после однократной активации worker-цикла в активном агентном сеансе.

## Активация

Передайте агенту следующую задачу:

> Подключись к SkillGraph MCP и включи worker-режим для текущего провайдера.
> Вызови `register_agent_runtime`, затем повторяй цикл:
> `claim_agent_run_task` → `resolve_agent_context` с `runId/taskId` →
> `start_agent_run_task` → выполнение и `record_agent_run_progress` →
> `record_agent_outcome` → `complete_agent_run_task` или
> `fail_agent_run_task`. После завершения запрашивай следующую задачу, пока
> очередь не станет пустой. Между длинными этапами отправляй
> `heartbeat_agent_runtime`.

Рекомендуемые capabilities:

- управляющий агент любого провайдера: `read`, `handoff`, `audit`, `plan`;
- агент-исполнитель любого провайдера: `read`, `write`, `review`, `handoff`, `audit`.

Значение `--client-provider` должно совпадать с полем «Провайдер» профиля агента:
`codex`, `cursor`, `claude`, `copilot`, `deepseek`, `qwen`, `local` или `custom`. Task Manager не
имеет отдельной привязки к Codex — его planning-узлы получает выбранный для него
провайдер. То же правило действует для всех остальных задач цепочки.

## Ограничение полуавтономного режима

Обычный stdio MCP не может разбудить бездействующий клиент. Если агентный сеанс
завершился, SkillGraph показывает ожидание соответствующего провайдера, сохраняет
очередь и продолжает после повторной активации worker-режима. Открытое окно без
зарегистрированной свежей runtime-сессии не считается готовым исполнителем.

## Безопасность

- Провайдер берётся из `--client-provider`; значение `unknown` запрещено.
- Worker получает только задачи своего провайдера.
- Одновременно в проект пишет не более одного worker.
- Артефакты должны находиться внутри директории подключённого проекта.
- Pause/cancel работают кооперативно; поздний результат сохраняется в аудите как
  orphaned attempt и не меняет состояние запуска.
